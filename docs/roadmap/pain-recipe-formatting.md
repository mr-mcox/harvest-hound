# Recipe Formatting for Cooking

**Status**: Later
**Impact**: Minor - Some friction while cooking
**Discovered**: 2025-12-21 (Week 3 production use), mentioned from tonight's cooking
**Related**: Charter Priority 1 "Recipe formatting for cooking"

## The Pain

Need to flip back and forth between ingredient list and instructions while cooking. Current formatting requires more scrolling/navigation than ideal.

## Why It Matters

Cooking friction - not blocking, but could be smoother. Mentioned as "slight pain" encountered during actual use.

## Solution Direction

Charter anticipated this: "Reduce need to flip back/forth while cooking"

Possible approaches:
- Inline ingredients in instruction steps
- Side-by-side ingredient/instruction view
- Progressive disclosure (show ingredients as needed per step)
- Print-friendly format

## Notes

Not critical urgency - steel thread works, this is polish. User assessment: "pretty much everything else has been addressed" from fidelity pass, this is a remaining item.

Lower priority than recipe editing and priority pairing based on actual impact.
